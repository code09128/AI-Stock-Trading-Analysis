1. 為什麼分成「🐍 Python 全端自建」與「⚡ No-Code Agent」兩種路線？

並非要你做兩套，而是依「團隊角色」與「開發階段」選擇最適合的落地方式
⚡ 路線 A：No-Code / AI Agent（快速驗證 MVP） 1～3 天上線

使用現成的 AI 平台（Gemini Gems / ChatGPT GPTs）搭配自動化串接工具（n8n / Make / Dify）與 Google Sheets。不需要寫複雜後端程式，適合先確認提示詞分析準不準。

適合對象：交易研究員、PM、或不打算維護伺服器的個人投資者。
最適合模組：模組 2（新聞轉策略）、模組 5（交易日誌檢討）。
🐍 路線 B：Python 全端自建（精準量化與自動化產品） 2～4 週開發

因為大型語言模型（LLM）不擅長算數學（直接問 AI 均線或過去 5 年回測勝率會產生嚴重幻覺），必須先用 Python 算好 100% 精確的指標、回測數據與相關係數，再餵給 AI 做邏輯推論。

適合對象：軟體工程師、量化開發者、或準備打造正式看盤系統的團隊。
最適合模組：模組 1（技術指標計算）、模組 3（回測）、模組 4（風控矩陣）。

2. 規則可量化性：3 條規則必須包含明確數字或時段門檻，可直接當下單前檢查表。

⚖️ 台股 (TWSE/TPEx) vs. 美股 (NYSE/NASDAQ) 系統底層規格對照表

            

              要讓第 1～5 模組同時支援台美股，資料處理層（Data Adapter）與回測／風控引擎必須先統一處理以下 8 大制度差異：
            

          

        


        

          

            
              

                系統設計維度
                🇹🇼 台股規格 (TW Market)
                🇺🇸 美股規格 (US Market)
                🛠️ 開發實作與防呆處理規範
              

            
            
              

                1. 標的代號與正規化
                純數字 4～6 碼（如 2330、0050），跨國 API 需加後綴 .TW（上市）或 .TWO（上櫃）。
                英文字母 1～5 碼（如 NVDA、AAPL、BRK.B）。
                建立 normalize_symbol()：輸入純數字自動查詢上市櫃清單補上後綴，並綁定中文／英文公司名稱供模組 2 新聞檢索使用。
              

              

                2. 交易單位與部位計算
                整張為 1,000 股，盤中／盤後零股為 1～999 股；價格跳動單位（Tick Size）隨股價區間階梯式變動（如 1000 元以上每檔 5 元）。
                標準以 1 股為單位（多數券商亦支援小數點碎股 Fractional Shares）；股價 ≥ $1 時最小跳動固定為 $0.01。
                模組 1 計算支撐壓力價位與模組 4 再平衡股數時，台股需套用 Tick Size 階梯函數對齊有效委託價（如台積電 2420、2425 元），避免算出無效委託價。
              

              

                3. 交易時段與時區對齊
                台北時間 Asia/Taipei (UTC+8) 09:00–13:30（無午休，13:25–13:30 集合競價收盤）。
                美東時間 America/New_York 09:30–16:00（對應台灣夏令 21:30–04:00、冬令 22:30–05:00），且財報常於盤前(04:00起)或盤後(16:00–20:00)公布。
                資料庫全面以 UTC 時間戳記儲存，模組 2 抓取美股財報新聞時必須納入盤前／盤後報價（Extended Hours），避免隔日開盤大幅跳空誤判。
              

              

                4. 漲跌幅限制與極端波動
                每日漲跌幅限制 ±10%（新股掛牌首五日無漲跌幅限制），觸及漲跌停可能出現流動性鎖死（買不到／賣不掉）。
                無每日漲跌幅限制（單日可暴漲或暴跌 30%+），僅有大盤指數熔斷（7%/13%/20%）與個股 LULD 5 分鐘暫停交易機制。
                模組 3 回測台股時，若當日最高價＝最低價＝漲跌停價，應禁止假設在該價位能 100% 成交；美股則需在模組 2 與模組 4 加入財報跳空風險緩衝。
              

              

                5. 交易稅費與摩擦成本
                買賣雙邊手續費定價 0.1425%（常有 2.8～6 折優惠）＋賣出時課徵 證交稅 0.3%（現股當沖減半為 0.15%，ETF 為 0.1%）。
                主流美股券商（IBKR/Firstrade/Schwab）免交易佣金（或每股 $0.005），僅賣出時收取極低 SEC/FINRA 規費；複委託則有 0.1%～0.25% 手續費。
                模組 3 回測分析師必須依市場載入不同成本模板（台股一買一賣約摩擦成本 0.4%～0.58%，高頻進出極易被稅費侵蝕獲利因子）。
              

              

                6. 委託有效條件 (ROD/IOC/FOK)
                支援 ROD（當日有效）、IOC（立即成交否則取消，允許部分成交）、FOK（全部成交否則取消）；搭配限價或市價。
                支援 DAY（等同 ROD）、GTC（取消前有效，最長 60～90 天）、IOC、FOK，且支援原生停損限價單（Stop-Limit）與移動停損（Trailing Stop）。
                模組 1 與模組 5 在產出進出場執行建議時，台股無原生跨日 GTC 單，需透過券商智慧單／雲端條件單或每日開盤前重送 ROD 單。
              

              

                7. 除權息與拆合股還權處理
                每年密集除權息（配息與配股），未還權日線圖會出現假性跳空下跌缺口。
                多為季配息，且科技股常見股票分割（Stock Split，如 1 拆 10）或反向合股。
                模組 1 計算長天期均線（MA60/MA200）與模組 3 進行歷史回測時，強制規定使用還權後股價（Adjusted OHLC）。
              

              

                8. 投資組合跨幣別匯率風險
                新台幣（TWD）計價，交割制度為 T+2。
                美元（USD）計價，交割制度自 2024 年起已改為 T+1。
                模組 4 同時分析台美股持倉時，需自動抓取最新 USD/TWD 匯率統一折算為基準貨幣（TWD 或 USD），並將美元匯率波動納入曝險分析。

from dataclasses import dataclass
import re

@dataclass
class MarketConfig:
    market: str          # "TW" or "US"
    symbol: str          # 正規化代號 e.g. "2330.TW" or "NVDA"
    currency: str        # "TWD" or "USD"
    lot_size: int        # 1000 (台股整張) or 1 (美股)
    commission_rate: float
    tax_rate: float      # 台股證交稅 0.003 / 美股規費 ~0.00002

def resolve_market_symbol(raw_ticker: str) -> MarketConfig:
    clean = raw_ticker.strip().upper()
    # 判斷是否為台股代號 (4~6碼數字，或結尾為 .TW / .TWO)
    if re.match(r"^\d{4,6}(\.TW|\.TWO)?$", clean):
        sym = clean if "." in clean else f"{clean}.TW"
        return MarketConfig(
            market="TW", symbol=sym, currency="TWD",
            lot_size=1000, commission_rate=0.001425 * 0.6, tax_rate=0.003
        )
    # 預設歸類為美股標的
    return MarketConfig(
        market="US", symbol=clean, currency="USD",
        lot_size=1, commission_rate=0.0, tax_rate=0.00002
    )
